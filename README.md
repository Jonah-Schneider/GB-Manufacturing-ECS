# GB Manufacturing ECS

Electronic Checkout System for tracking employee equipment usage.

## Technology Stack

- HTML
- CSS
- JavaScript
- Python (Flask)
- SQLite

## Steps to Run Project
- Install Python and a IDE such as VS Code (used with project) use https://www.python.org/downloads/ and https://code.visualstudio.com/download
- Clone GitHub Repo using "git clone https://github.com/Jonah-Schneider/GB-Manufacturing-ECS"
- Install the requirements for the project using "pip install -r requirements.txt" in the terminal
- Run Backend servers by going into App.py
- Run and use frontend by going into script.js
